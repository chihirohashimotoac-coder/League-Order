# ハリマル 追加素材の制作依頼 (PR2 時点)

2026-11-18 作成。PR2 で、素材 v0.2 (待機・歩行・睡眠の 12 コマ) では描けない動作を「素材待ち」にしている。
このファイルを ChatGPT にそのまま渡して、追加素材の制作を依頼できるようにまとめた。

## 1. 共通の納品規格 (v0.2 と同じ)

| 項目 | 規格 |
|---|---|
| 1 コマの枠 | 30 × 20 CSS px (1x = 30×20 実ピクセル、2x = 60×40、3x = 90×60) |
| 全高 | 通常の姿勢は、足先から耳・背中の針の最高点までが **20 CSS px 以下**。伏せる・のぞく姿勢は低くてよい |
| 基準点 | 枠の下辺中央が足元 (v0.2 と同じ)。ぶら下がり・しがみつきは、つかむ前足の位置を別に指定する |
| 向き | 元の絵は **左向き**。右向きは左右反転で表示する (頬のマーク等の反転は許可済み) |
| 背景 | 透明 PNG。1x / 2x / 3x の 3 解像度 |
| 形式 | 動作ごとに横 1 行のスプライト (コマ数 × 30 CSS px)。v0.2 のアトラスに行を足す形でもよい |
| 一貫性 | 猫耳・丸い体・短い 4 本足・フライト形の針・顔を、v0.2 と同じ輪郭と配色で描く。コマごとに体格や顔が変わらないこと |
| 確認 | 20 CSS px の等倍で、ライト・ダークの背景の上で読めること |

## 2. 必要な動作 (優先順)

| 優先 | 動作 (アプリの名前) | 使う場面 | コマ数の目安 | ポーズの指定 |
|---|---|---|---|---|
| 1 | 転ぶ・起き上がる (`tumble`) | ジャンプの着地失敗、速いスクロールのあと | 転ぶ 4〜6、起き上がる 3〜4 | 横に転がる (体を丸めて 1 回転に見える連続)。最後は座った姿勢から待機へ |
| 2 | 縁で滑る・しがみつく・よじ登る (`slip` / `hang` / `climb`) | カードの縁で足を滑らせる | 滑る 2〜3、しがみつき 4、よじ登り 4〜6 | 片足が縁から外れて傾く → 前足 2 本で縁をつかみ、後ろ足をバタバタ (ループ) → 体を引き上げて縁に乗る。**つかむ前足の位置 (縁の線) を全コマで同じ高さに** |
| 3 | 驚く (`surprise`) | 背後から触れられたとき | 2〜3 | 目を見開き、針が少し逆立つ。小さく跳び上がる動きはアプリ側で付ける |
| 4 | 毛づくろい (`groom`) | 自分から選ぶ日常の行動 | 4〜6 (ループ可) | 座って前足をなめる・顔を洗う |
| 5 | 伸び (`stretch`) | 休んだ・眠ったあと | 3〜4 | 前足を前に伸ばしてお尻を上げ、背を反らす → 戻る |
| 6 | 見上げる・首をかしげる (`lookUp` / `tilt`) | 止まったカーソルの近く (PC) | 各 2〜3 | 頭だけを上げる / 頭だけを傾ける (体ごと回さない) |
| 7 | じゃれる (`play`) | 速く動くカーソルの近く (PC) | 3〜4 (ループ可) | 前足で空中をたたく |
| 8 | 寝ぼけて落ちそうになる (`sleepyFall`) | 眠っている途中 | 3〜4 | 丸まったまま縁でぐらっと傾く → はっと目を開けて戻る |
| 9 | カーソルにぶら下がる (`cursorHang`) | PC のカーソルの近く | 2〜4 | 前足でつかまってぶら下がり、後ろ足が揺れる。**つかむ点の位置を指定** |
| 任意 | 走る (`run`) | 急に駆け出す | 4〜6 | いまは歩行コマを速く再生している。専用の走りコマがあればより自然 |
| 任意 | 喜ぶ (`happy`) | 顔に触れたとき | 2〜3 | うれしい表情 (目を細める)。跳ねる動きはアプリ側で付ける |

## 3. アプリ側の対応

- 動作と素材の対応表は `src/features/harimaru/clips.ts`。素材が届いたらコマを `sprite.ts` に足し、表の
  `available` を `true` にすれば、行動の抽選・反応の対象になる (状態遷移・発生条件・安全判定は実装済み)。
- 素材が届くまでは、その動作を選ばない。代わりの見た目では埋めない。ただし「背後から触れる」は、驚く素材が届くまで「振り向く」反応にしている。
