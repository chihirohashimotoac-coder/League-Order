## 最優先条件（確定）

- ハリマルは4足歩行の小型マスコット。動作の最重要特性は**気まぐれさ**。
- アプリの情報閲覧・操作を妨げない。スコア・ボタン・文字・固定バー・モーダル等を保護。
- 通常時は足先から耳・背中の針まで**全高20 CSS px**。横幅は試作目安28〜30 CSS px（確定値ではない）。
- 現行のオーダー生成、n01取得、スコア、データ保存、画面遷移などの仕様・ロジックを変更しない。
- 新しいライブラリ導入は無断で行わない。PR単位の開発・検証。mainへの直接pushは禁止。

## ユーザー回答による11項目の確定

1. 20pxで潰れる頬のマーク・首飾りなどの細部は省略可。
2. 右向き・左向きのスプライトの左右反転を許可。
3. 安全な配置場所がある場合は全画面に表示する。
4. 表示は初期ON、ユーザーが任意でOFFにできる。
5. OSまたはブラウザーの「動きを減らす」設定がONなら**非表示**。
6. ハリマルへのタップ・クリックの反応は既存操作に干渉しない安全領域のみ。
7. 味方チームはアプリに登録中のチームで判定。確証がない場合は中立。
8. 01の得点反応は高得点100点以上、低得点1〜40点。得点欠損・0点・初回履歴の扱いは技術設計を確認。
9. 180達成時は通常の高得点反応より優先して特別な驚きモーション。
10. 試合勝利を中心に反応。Leg・Set勝利は控えめに反応する。逆転判定の集計単位は別途確認。
11. Cricket得点への反応は初回の対象外とし、後のフェーズで対応。

## 確定している動作要求

### 日常・自発行動
- カード上の安全な余白を歩く、駆け出す、ジャンプ、毛づくろい、眠る。
- 無操作が続くと眠る。休憩後に伸びをする。
- 全行動を機械的に繰り返さず、直前の行動と周辺状況に応じて気まぐれに行動。

### UIアスレチック
- カード間を移動し、カードの裏からひょっこり覗き、隠れる。
- 足を滑らせて前足でカードにしがみつき、後ろ足をバタつかせてよじ登る。
- 寝ぼけて落ちそうになる。着地失敗で転がって立ち直る。
- 高速スクロールで転ぶ。画面外へ出て別の安全地点から再登場。
- ページ移動後、遅れて到着先に現れる。

### 操作に反応
- 安全な余白でのタップ・クリックで喜ぶ。
- カーソル・タップに気まぐれに近づき、覗く。静止したカーソルを見上げて首をかしげる。
- しっぽ・背中に触れると振り向く／驚く。顔に触れると喜ぶ。連続接触では逃げる。
- PCのみカーソルにじゃれたり、ぶら下がったりする。端末のタッチ操作・入力等は妨げない。

### 01観戦
- 味方の高得点：驚く。味方の低得点：慌てる。敵の高得点：焦る。
- 味方の勝利：喜ぶ。敵の勝利：悔しがる。逆転：飛び上がる。
- 180達成時は専用の驚き。Leg・Set勝利は控えめな反応。
- 初回に取得した過去のスコアや再取得の重複で反応させない。味方不明なら中立。

## Work調査に基づく推奨設計（ユーザー確定の数値ではない）

- React上にキャラクター専用レイヤーを1つ追加し、既存画面のDOMや操作イベントを壊さない。
- レイヤーは `pointer-events: none`・`aria-hidden=true`。反応は安全領域へのポインタイベント検出で処理。
- 足場や経路は実DOMの余白を計測。狭ければ無理にジャンプせず非表示移動。
- 行動判断は状態遷移＋重み付き確率。固定タイマー・乱数を差し替え可能にしてテストする。
- フレーム描画はCSS transformとスプライトシート。スコア・カーソル変化でアプリ全体を再描画しない。
- n01連携は既存の観戦データのみを参照し、余分なリクエストを発生させない。

## 素材（今回の試作）

- 待機：4フレーム（瞬き）
- 歩行：4フレーム（脚の位相差）
- 睡眠：4フレーム（眠りへ移行）
- 配信用試作は透明PNG、1x / 2x / 3x。スプライトシートは横4列×縦3行。
- 表示枠は1フレーム 30×20 CSS px（キャラクターの**実際の可視高さは最大20 CSS px**）。
- アニメーションタイミングは仮置き。最終確定前に20pxでループの自然さ・輪郭・足の滑りを検証する。
- ※今回の生成物は原案からの試作素材であり、正式なアセット承認済みではない。
